# 脑袋加一

简约的英语阅读与词汇学习网页，当前为访客试用版。

## 在线试用

https://ouoing.github.io/naodai-plus-demo/

- 阅读：推荐文章、新闻短读、查词、句子讲解、中文译文与批注
- 词汇：四级、六级、考研、雅思方向，认词、拼写与语境填空
- 词本与笔记：集中查看，支持本机学习记录和备份
- 数学：极限与无穷小示例，含交互演示与自测

## 试用说明

无需注册，选择“先体验”即可开始。建议分别尝试读完一篇文章、学习一组词汇、保存一条笔记，再检查返回与刷新。

反馈时请注明手机/电脑型号、浏览器、操作步骤，以及截图或报错。浏览器桌面验证不能代替手机真机手势验证。

## 数据保存

当前不提供账号登录和跨设备同步。学习记录保存在所选浏览器本地，或只保留本次会话。清理浏览器数据可能丢失记录。

不同网址属于不同存储空间：原站记录不会自动出现在 GitHub Pages。需要迁移时，请先从原站导出完整学习备份，再在新站“我的”页面导入；导入前请核对预览。

## 素材与许可

文章、图片、字体各有独立的来源和许可，保留在页面、数据文件和相应资源目录中。公开源码不代表第三方素材可以不受限制地使用。本站辅助讲解不替代官方考试资料，新闻不是实时自动更新。

## 本地运行

这是静态网页。可使用任意静态 HTTP 服务从仓库根目录提供文件，不需要 API 密钥或服务端数据库。不要通过直接双击 HTML 的 file:// 方式运行，因为数据加载需要 HTTP。

本仓库由已验证的 v51 网页文件快照迁入，保留原数学 Demo 的提交历史。
