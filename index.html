高等数学 · 极限 01

无限接近，
但从未抵达

难度：基础

先想象一个数：它今天是 0.1，明天是 0.01，后天是 0.001。它正在稳定地靠近零。无论你把时间推到多远，它都可以比昨天更小。

但只要小数点后仍然有一个 1，它就不是零。数学里，“越来越接近”和“最终就是”是两件不同的事。

01 / 一个简单的序列先别急着背定义

取数列 aₙ = 1/n。当 n 不断变大，aₙ 会越来越小。给定任意一个很小的正数，我们总能让 n 足够大，使 1/n 比它还小。

把 n 向右推 n = 10，1/n = 0.1000
0 1/10
n = 1n = 1000

拖到最右边时，那个点已经很靠近零了，但它仍然在零的右侧。只要 n 是有限的，1/n 就永远大于零。

limn→∞ 1/n = 0 这句话描述的是变化趋势，而不是某一项的实际取值。
02 / “等于 0”到底在说什么关键区别

极限等于零，意思是：数列的项最终可以落进零附近任意小的范围里。这个范围无论有多苛刻，我们都能做到。

它并没有说数列中的某一项必须取到零。极限关心的是“往哪里去”，不是“有没有到”。

无穷小不是一个神秘的、比所有正数都小的固定数字。它描述的是一个以零为极限的变量。
03 / 严格地说定义

“任意接近”可以写得非常精确。无论给出多小的正数 ε，都能找到一个位置 N；从那以后，数列的每一项与零的距离都小于 ε。

∀ ε > 0，∃ N，当 n > N 时，|1/n| < ε 对 aₙ = 1/n，只需取 N > 1/ε。

例如要求距离小于 0.001，只要让 n > 1000 即可。这里没有“真的到达零”，只有一个可以满足任意精度的过程。

04 / 一个变式符号不影响趋近

再看 bₙ = (−1)ⁿ/n。它一会儿在零的左边，一会儿在右边，看起来不断摆动；但它与零的距离仍然是 1/n，因此极限依然是零。

判断是否趋近于零时，可以先观察绝对值。方向在变化，距离仍可能稳定缩小。
