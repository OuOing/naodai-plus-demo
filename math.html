高等数学 · 极限 01

极限与无穷小

先想象一个数：它今天是 0.1，明天是 0.01，后天是 0.001。它正在稳定地靠近零。无论你把时间推到多远，它都可以比昨天更小。

但只要小数点后仍然有一个 1，它就不是零。数学里，“越来越接近”和“最终就是”是两件不同的事。

01 / 一个简单的序列先别急着背定义

取数列 aₙ = 1/n。当 n 不断变大，aₙ 会越来越小。给定任意一个很小的正数，我们总能让 n 足够大，使 1/n 比它还小。

拖到最右边时，那个点已经很靠近零了，但它仍然在零的右侧。只要 n 是有限的，1/n 就永远大于零。

limn→∞ 1/n = 0 这句话描述的是变化趋势，而不是某一项的实际取值。
02 / “等于 0”到底在说什么关键区别

极限等于零，意思是：数列的项最终可以落进零附近任意小的范围里。这个范围无论有多苛刻，我们都能做到。

它并没有说数列中的某一项必须取到零。极限关心的是“往哪里去”，不是“有没有到”。

无穷小不是一个神秘的、比所有正数都小的固定数字。它描述的是一个以零为极限的变量。
03 / 严格地说定义

“任意接近”可以写得非常精确。无论给出多小的正数 ε，都能找到一个位置 N；从那以后，数列的每一项与零的距离都小于 ε。

∀ ε > 0，∃ N，当 n > N 时，|1/n| < ε 对 aₙ = 1/n，只需取 N > 1/ε。

例如要求距离小于 0.001，只要让 n > 1000 即可。这里没有“真的到达零”，只有一个可以满足任意精度的过程。

04 / 一个变式符号不影响趋近

再看 bₙ = (−1)ⁿ/n。它一会儿在零的左边，一会儿在右边，看起来不断摆动；但它与零的距离仍然是 1/n，因此极限依然是零。

判断是否趋近于零时，可以先观察绝对值。方向在变化，距离仍可能稳定缩小。
05 / 典型例题夹逼

判断数列 cₙ = n/(n² + 1) 是否为无穷小，并说明理由。

展开解答
1

先看符号：当 n 为正整数时，cₙ > 0。

2

比较大小：n² + 1 > n²，所以 0 < n/(n² + 1) < n/n² = 1/n。

3

因为 1/n → 0，根据夹逼定理，cₙ → 0，因此 cₙ 是无穷小。

4

注意：cₙ 的每一项都大于零。它是无穷小，并不意味着某一项等于零。

06 / 无穷小的运算规则与边界

有限个无穷小相加、相减仍是无穷小；无穷小乘以有界量仍是无穷小。若 aₙ → 0、bₙ → 0，那么 aₙ + bₙ → 0；若 |cₙ| ≤ M，则 aₙcₙ → 0。

除法不能照搬：两个无穷小相除，结果可能是 0、非零常数，也可能发散。比如 (1/n²) ÷ (1/n) → 0，而 (1/n) ÷ (1/n) = 1。

先看表达式的结构，再决定能否使用无穷小运算法则。分母也趋零时，应单独分析比值。
07 / 等价无穷小计算工具

当 x → 0，如果 f(x)/g(x) → 1，就写作 f(x) ∼ g(x)。这表示两者趋零的速度相同，适合在乘积、商式中替换。

sin x ∼ x，1 − cos x ∼ x²/2，ln(1+x) ∼ x以上都以 x → 0 为前提。

例如 limx→0 sin(3x)/x = 3，因为 sin(3x) ∼ 3x。使用时要检查趋近点；不能把“等价”当作任意式子的恒等替换。

08 / 典型例题等价替换

求 limx→0 (1 − cos x)/(x sin x)。

展开解答
1

当 x → 0，分子 1 − cos x ∼ x²/2。

2

分母 x sin x ∼ x · x = x²。

3

所以原式的极限为 (x²/2)/x² = 1/2。

09 / 比较无穷小的阶谁趋零得更快

只说两个量都趋于零，通常还不够。令 aₙ = 1/n、bₙ = 1/n²；它们都是无穷小，但 bₙ/aₙ = 1/n → 0，因此 bₙ 比 aₙ 更快趋零，称 bₙ 是 aₙ 的高阶无穷小。

考题中常把“同阶”和“高阶”放在一起判断：若 bₙ/aₙ → 非零常数，两者同阶；若比值趋于零，分子是分母的高阶无穷小。比较前务必先写清谁除以谁，否则结论容易颠倒。

等价无穷小不能随意用于减法。例如 sin x − x 的首项正好抵消；直接把 sin x 换成 x，只会得到 0，无法判断它与 x³ 的比值。此时要继续展开：sin x = x − x³/6 + o(x³)。
10 / 综合例题先整理再求极限

求 limn→∞ (√(n²+n) − n)。

展开解答
1

直接代入得到“∞ − ∞”，不能分别求极限再相减。

2

分子分母同乘 √(n²+n) + n，原式变为 n/(√(n²+n) + n)。

3

上下同除以 n，得到 1/(√(1+1/n) + 1) → 1/2。

11 / 易错辨析三个判断
正确
常数数列 0, 0, 0, … 是无穷小，因为它的极限是零。
错误
“无穷小是一个非常小的常数。”无穷小描述变量的变化趋势，不是某个固定数。
错误
“两个无穷小相除仍是无穷小。”例如 (1/n) ÷ (1/n) = 1。
练习 / 自测单选

选择一项，即时查看解析；可以重新选择。

本期复盘
  1. 无穷小是以零为极限的变量，不是一个固定的小数。
  2. 极限等于零，不要求数列中的某一项实际取到零。
  3. 判断时可以使用定义、绝对值和夹逼；运算时要留意商式。
  4. 等价无穷小适合在乘积和商式中替换，前提是趋近点正确。
